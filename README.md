# UYFund Management System — public frontend

This repository hosts **only** the public static interface. No NPO records, documents, credentials or private JSON backups belong here.

Private data remain in `zvuk71/uyfund-management` on branch `uyfund-data` and are accessed through GitHub API with a fine-grained personal token entered by the user in the browser. Never paste tokens in issues or commits.

GitHub Pages: Settings → Pages → Build and deployment → GitHub Actions.
